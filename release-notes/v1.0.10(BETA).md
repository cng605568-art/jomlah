# v1.0.10 (BETA): Kembali ke peta klasik · 恢复经典地图 · Back to the classic map
**Kemas kini biasa: pasang terus atas versi lama, tak perlu buang.**

### Diubah
- 🗺️ Peta baharu dibuang kerana terlalu banyak masalah di telefon. App kini guna peta klasik OpenStreetMap sahaja, dengan peta malam seperti dulu.

Semua yang lain kekal: kereta yang stabil (v1.0.9), trafik langsung, lapor dengan suara dan amaran versi baharu.

**Regular update: install straight over the old version, no need to uninstall.**

### Changed
- 🗺️ The new map has been removed because it caused too many problems on phones. The app now uses only the classic OpenStreetMap map, with the night map as before.
- ⚙️ The "Map style" option in Settings is gone (there is nothing left to choose).

Everything else stays: the steadier car (v1.0.9), live traffic, voice reports and new-version alerts.
